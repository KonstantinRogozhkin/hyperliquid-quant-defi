## 2. Монте-Карло стресс-тест исполнения и аудит маржи (500 путей, Holdout 45d, 1x)

Модуль: [execution_stress.py](../../../src/hl_quant/execution_stress.py).

| Сценарий (500 путей) | Full Holdout (med APR / p05 / med Sh / P>0 / DD) | Ex-`INIT` Holdout (med APR / p05 / med Sh / P>0 / DD) |
|---|---|---|
| `base_maker` | +29.45% / +29.45% / Sh 4.02 / 100% / −1.54% | +13.69% / +13.69% / Sh 2.41 / 100% / −1.78% |
| `mild_l2_friction` (15% miss, 0–2 б.п. slip, 5% 1h delay) | **+17.13%** / +8.03% / **Sh 2.30** / **99.4%** / −1.96% | **+1.08%** / −7.48% / Sh 0.18 / 59.0% / −2.37% |
| `harsh_limit_misses` (30% miss, +7 б.п., 15% 1h delay) | −7.06% / −20.82% / Sh −0.89 / 17.6% / −3.65% | −23.27% / −37.42% / Sh −3.60 / 0.0% / −4.17% |
| `extreme_stress` (50% miss, +12 б.п., 25% 1h delay) | −37.71% / −54.90% / Sh −4.53 / 0.0% / −6.54% | −54.37% / −71.09% / Sh −7.77 / 0.0% / −7.18% |

**Аудит одноногой просадки HL (буфер маржи до ребалансировки залога между биржами):**
- `1x`: худшая 24h одноногая просадка `−4.09%`, худшая 72h `−4.62%` → рекомендуемая свободная маржа `>= 15.0%`.
- `2x`: худшая 24h `−8.19%`, худшая 72h `−9.24%` → рекомендуемая свободная маржа `>= 23.1%`.
- `3x`: худшая 24h `−12.28%`, худшая 72h `−13.86%` → рекомендуемая свободная маржа `>= 34.6%`.

**Ключевой вывод стресс-теста:** стратегия уверенно выживает при реалистичном `mild_l2_friction` (что согласуется с измеренным живым L2-спредом `0.88 б.п.`), но **ломается при >= 30% промахов лимиток** из-за оборота `xs_rev_L24_r12`. Значит, качество пассивного исполнения лимитками (fill rate >= 85%) — критическое условие перед любым live-пилотом.

### Пересчёт стресс-теста после PR #13

Таблица выше посчитана вручную, на весах paper-трекера (`carry_best_cex_L168_in5 0.400`, `carry_best_cex_L72_in10 0.233`, `xs_rev_L24_r12 0.209`, `xs_mom_L72_r24 0.158`; они воспроизводят `base_maker +29.45% / Sh 4.02`) и кодом до исправления издержек смены биржи. Как именно тогда строились оборот и подверженность шоку ноги, не записано, поэтому точно повторить строки трения не удалось. Теперь стресс воспроизводим: `scripts/analytics/run_hl_metamodel_stress.py` (логика — `execution_stress.metamodel_stream`), 500 путей, seed 42:
- трение (промахи лимиток, проскальзывание) начисляется на проторгованный номинал в единицах капитала: кросс-биржевое изменение `dw` торгует `dw · C/2` на каждой из двух ног, то есть `dw` капитала (смена биржи CEX-ноги учитывается), однобиржевое — `dw`;
- шок 1h незахеджированной ноги действует только на кросс-биржевые сделки (номинал одной ноги, `cex_turnover / 2`); однобиржевые слои HL (`xs_rev`, `xs_mom`) его не получают; масштаб шока — медиана по монетам 24h std часовой доходности HL.

**Поправка к выводу:** при мягком L2-трении (15% промахов лимиток, 0–2 б.п. проскальзывания) метамодель остаётся в плюсе и без `INIT`: `+6.4%` со старыми весами и `+13.5%` с новыми Dev-весами, вероятность плюса почти 100%. При `>= 30%` промахов без `INIT` обе версии уходят в минус. Новые Dev-веса выше старых по уровню во всех сценариях, кроме `extreme_stress`, но не устойчивее: из-за большего оборота `xs_rev` они теряют на трении больше п.п. Критическое условие перед live-пилотом не меняется: fill rate ALO не ниже ~85% на реальном обороте `xs_rev` (см. [hl_microstructure_alo_markout.md](hl_microstructure_alo_markout.md)).
